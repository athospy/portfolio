Ardu

Prompt engineering + LLM evaluation pipeline on a self-hosted model

A working mobile app built as a real-world testbed for prompt engineering. Runs a 1.5B LLM locally via Ollama on a 2GB VPS, constraint-driven prompting was the core challenge. Built an 8B judge model evaluation framework to score outputs on relevance, originality, and clarity, plus a two-gate generation pipeline (lexical overlap + Jaccard similarity) to reject low-quality or near-duplicate outputs. Iterative tuning moved relevance scores from 1.6 → 2.3/3. Available on iOS and Android.

React Native Node.js Ollama (LLM) PostgreSQL Prompt Engineering

✓ Live on iOS TestFlight & Android Beta, self-hosted LLM on a 2GB VPS
